# UKEC Study-Abroad Livestream Launch Skill

这个 Skill 用于快速生成 UKEC 泛留学直播的轻量化启动方案。

它适合高考后、本科、硕士、低龄留学、申请规划、国家选择、专业选择、考试备考、Offer 决策、签证行前、家长决策等直播场景。

## 适合解决什么问题

当你需要策划一场留学直播时，不需要每场重新写完整策划案。只要输入本场直播的基础变量，这个 Skill 会自动生成一套可执行的轻量启动方案。

每场重点替换：

- 直播阶段
- 面向人群
- 直播主题
- 嘉宾信息
- 用户痛点
- 主持人问题
- 资料钩子
- 抽奖机制
- 直播间福利
- 小助手承接话术

## 调用方式

在 Codex 中可以这样调用：

```text
Use $ukec-study-abroad-live-launch to create a lightweight launch plan for this study-abroad livestream.
```


## 最小输入示例

```text
直播时间：7月7日17:00
直播主题：27Fall硕士暑假准备留学专场
面向人群：计划申请27Fall硕士的学生和家长
直播形式：座谈会，1个主持人+2个嘉宾
嘉宾姓名和身份：2位UKEC顾问老师
用户痛点：不知道现在准备早不早，不知道暑假该先考语言、找实习还是选学校
资料钩子：27Fall硕士申请暑假准备清单
直播间福利：免费1v1硕士申请规划名额
```

信息不完整也可以使用，Skill 会合理补全，并把不确定内容标注为 `【待确认】`。

## 默认输出

每次会输出：

1. 本场类型判断
2. 单场直播启动表
3. 主持人提问设计
4. 嘉宾答题卡
5. PPT轻量版结构
6. 主持人口播模块
7. 小助手承接话术
8. 待业务确认事项

如果直播形式是座谈会、双嘉宾或多嘉宾，还会额外输出：

9. 双嘉宾/多嘉宾回答侧重表

## 固定转化链路

所有直播默认使用这条链路：

```text
评论区关键词 → 小助手 → 资料领取 → 用户信息收集 → 1v1评估/顾问咨询 → 顾问承接
```

## 双嘉宾座谈会逻辑

当直播形式为 `1主持人+2嘉宾`、`双嘉宾直播` 或 `座谈会` 时，Skill 会自动拆分两位老师的回答侧重：

- A老师：讲框架、标准、时间线、判断逻辑、策略
- B老师：讲场景、案例、落地动作、常见误区、执行建议

这样可以避免两位老师重复回答同一个问题，让直播更像自然座谈。
